# Roadkill: Don't Hit 'Em

Night highway. One tank. Swerve, honk, or pay the body shop.

A 2D driving game: keep the rust-red pickup off the wildlife, keep the tank off empty, and don't take more than four hits.

## Play

- **Steer** A / D
- **Throttle / brake** W / hold S
- **Horn** Space (frozen deer wake up)
- **Pause** Esc

On a phone: horn on the left, drive pad on the right.

**Drive** starts Night 1. **Lesson** is the tutorial.

## Pickup

- Coffee — invincible for a few seconds
- Horseshoe — bonus points
- Spare tire — patch 25% damage
- Gas can — fill the tank

## Run it

```bash
npm install
npm run dev
```

Open the URL Vite prints. Requires Node 22+.
